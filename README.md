# Comfy Agent custom-node demo lab

Public summary cards comparing matched Comfy Agent custom-node runs with and without ecosystem code search.

The page is generated from schema-validated evidence. Failures and missing evidence remain visible. Detailed artifacts stay private until an explicit field-level public-export check passes.

This export holds 22 matched pairs. Every file is produced deterministically by an exporter that enforces a field allowlist, a file allowlist, SHA-256 verification against the run manifests, a privacy reject gate, and a link-integrity check.
