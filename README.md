# Comfy Agent custom-node demo lab

Public summary cards comparing matched Comfy Agent custom-node runs with and without ecosystem code search.

The page is generated from schema-validated evidence. Failures and missing evidence remain visible. Detailed artifacts stay private until an explicit field-level public-export check passes.

Comparison eligibility additionally requires retained, model-visible snippet text with repository,
exact commit, file, and inclusive line-range provenance before the first successful package write.
Empty, broken, unrelated, declaration-only, or operator-fetched context remains diagnostic. The
machine-readable contract is `evidence-schema.json`; run `python -m unittest tests/test_comparison_gate.py`.
